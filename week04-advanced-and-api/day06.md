- ❌→✅ **假会 ①**：`int[]` 的默认值说成"空值"——**基本类型默认是 0，引用类型才是 null**
  - `new int[3]` → `[0,0,0]`；`new String[3]` → `[null,null,null]`；`new boolean[3]` → `[false,false,false]`
  - **这个认知正是"补零对齐"能这么轻松的原因**：`new int[]` 出来天然全是 0
  - 且数组元素是 `[0,0,1,3,3]`（int 数组），不是字符串 `00133`

## 认知突破：循环里的数组会滚动变化 ⭐
- **我一开始的思维错误**：以为每一轮都对着**初始数组**做交换
- **实际**：每轮操作的是**上一轮改完的结果**，只有第一轮碰的是原始值

以 `"abc"` 打乱为例：

| 轮次 | 我以为在操作的 | 实际在操作的 |
|---|---|---|
| i=0 | `[a,b,c]` | `[a,b,c]` ← 只有第一轮是原值 |
| i=1 | `[a,b,c]` ❌ | `[c,b,a]` ✅ |
| i=2 | `[a,b,c]` ❌ | `[b,c,a]` ✅ |

**推广**：循环体内对数组/集合做原地修改，下一轮看到的就不是原样了——
冒泡排序、插入排序、双指针交换（344）、快排分区、数组去重**全是这个道理**。
分析循环要**跟着状态走**，不能盯着初始值。

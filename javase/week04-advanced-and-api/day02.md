## LeetCode 88 合并两个有序数组
- 第一版 bug 一堆：循环条件 `i > m+n` 永远假、方向 i++ 反了、比较对象/写入位置不移动、
  索引混淆（nums1[n-1] 的 n 是 nums2 长度）
- **m > n 的情况**：从后往前填的好处——nums1 剩余部分已在正确位置，不用动
- 第二版差一行：第二循环漏了 `k--`（多个剩余元素会覆盖同一格）
- 补上 `k--` 后通过 ✅
- 认知：**三指针从后往前填**是合并有序数组的标准姿势

## 🐛 重写引入的新 bug（待明天修）
### P0：takeDamage 双重扣防御 → 高防敌人越打越肥
- `Character.takeDamage` 加了 `damage -= defense;`，但 `FightingGame.calculateDamage` **已经减过一次防御**
- 后果：玩家攻击 14 vs 坦克防御 20 → calculateDamage 保底 1 → takeDamage 里 `1-20=-19` → `HP -= -19` → **坦克回血 19，永远打不死**
- 生命汲取同理：`player.takeDamage(10)` 在玩家防御 ≥10 时变成**自奶**
- 原则：**同一个计算只留一个权威出口**（防御要么在 calculateDamage 减，要么在 takeDamage 减，不能两处都减）

### P1：注册长度校验被 contains 带歪
- `if (!checkLen(...)) { if (contains(...)) { 提示; continue; } }` —— 长度不合法但用户名不重复时**不提示也不 continue**
- 后果：2 位用户名可注册成功
- 修法：长度不合法直接提示 + continue，`contains` 属于后面"唯一性"那一步，不该嵌进格式判断里

### P2：count++ 加了两次，场次编号跳号
- 胜利时 `count++` + 继续时又 `count++` → 第 1 场打完显示"第 3 场"
- 修法：只留继续分支那处（与原版一致）

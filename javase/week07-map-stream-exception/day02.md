### 源码速览要点（课后整理，留印象级别）
- **底层结构**：`Node<K,V>[] table`（数组）+ 链表 + 红黑树，三件套挂在同一个数组上
- **hash 扰动**：
  ```java
  static final int hash(Object key) {
      int h;
      return (key == null) ? 0 : (h = key.hashCode()) ^ (h >>> 16);
  }
  ```
  索引只取低位（`(n-1) & hash`），高位本来用不上；把高 16 位**异或**到低位，让高位也参与定桶，减少碰撞
- **容量是 2 的幂**：`(n-1) & hash` 只有当 n 为 2 的幂时才等价于 `hash % n`，而且位运算比取模快
- **put 主流程**（`putVal`）：
  1. `table` 为空或长度为 0 → 先 `resize()` 初始化，默认 16
  2. 定位桶 `(n-1) & hash`，桶为空 → 直接 `new Node` 放进去
  3. 桶首节点 key 相等（hash 相同且 `==` 或 `equals`）→ **覆盖 value 并返回旧值**
  4. 桶首是树节点 → 走 `putTreeVal` 红黑树插入
  5. 否则遍历链表：中途找到相等 key → 覆盖；走到尾 → **尾插**新节点
  6. 插入后：链表长度 > 8 **且** `table.length >= 64` → 树化；链表长 > 8 但数组 < 64 → **先扩容**
- **扩容**：阈值 = 容量 × 0.75（默认 16 × 0.75 = 12），超过就翻倍到 32
- **扩容后元素位置**：`e.hash & oldCap` 为 0 → 留原索引；不为 0 → 原索引 + oldCap。所以扩容后每个元素**只可能待在两处之一**，不用重新算 hash

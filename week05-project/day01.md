## 10 题验收（口答 8：3 对 3 错，2 撤销；手写 2 押后）
- ✅ 报 API：增删改查 5 方法 + 两个重载、返回值全对（概念表述一次过）
- ✅ 插入索引范围：`add(3, x)` 合法（size=3 时是尾部插入）、`add(4, x)` 报错
- ✅ `list.add(1)` 中间发生自动装箱 `1 → Integer`
- ❌ **假会 ①（重载陷阱，本次最大收获）**：把两个 remove 记反了
  - `list.remove(0)` → 实参是 int 字面量 → 调 `remove(int index)`，按**索引**删
  - `list.remove("0")` → 实参是对象 → 调 `remove(Object)`，按**值**删
  - `ArrayList<Integer>` 想删**值为 0** 的元素必须写 `list.remove(Integer.valueOf(0))`，直接写 `remove(0)` 删的是索引 0！
  - 口诀：**实参是 int 字面量按索引删，实参是对象按值删**
- ❌ **假会 ②**：只知道"越界会报错"，报不出类名 → **IndexOutOfBoundsException**（信息形如 `Index: 4, Size: 3`）；术语要张嘴能报
- ❌ **假会 ③**：以为 add 返回 false 的情形是"类型不符"
  - 类型不符是**编译期错误**，泛型根本不放行，走不到运行时
  - `ArrayList.add` **永远 true**；会返回 false 的是 Set 这类不允许重复的集合

## LeetCode 977 有序数组的平方（week05 第 1 题）
- **第一次全程独立完成** ✅：平方原地写回 + 手写冒泡排序，24m14s（踩线 25 分钟内），137/137 通过
- 但 616ms 只击败 5.31% —— 冒泡 O(n²)，进阶目标 O(n) 未达标
- 小冗余：`count` 与 `i` 永远同步，`nums[count]` 直接写 `nums[i]` 即可
- **学双指针 O(n) 思路**：
  - 核心观察：非递减数组里，**任意连续区间的平方最大值一定在两端之一** → 每轮只比较左右两端平方
  - 新数组**从后往前填**（`k = n-1` 起，每填一次 `k--`），谁赢谁的指针挪一格，输的不动
  - 停止条件 `while (left <= right)`：`left == right` 时区间还剩一个数要处理
  - 易错点：`k--` 放 if/else 外面两边共用；**必须 new 新数组**（边比边填会覆盖 nums 里未比较的原始值）
  - 走表验证 `[-4,-1,0,3,10]` 五轮 → `[0,1,9,16,100]`
- **关掉重写后提交：137/137 通过，1ms 击败 100.00%** ✅（23:13）

## 6 题快检（3 对 / 2 错 / 1 修歪）
- ✅ 双层 while 分工：外层 = 整局游戏（玩家活着就继续下一场），内层 = 本次对战回合
- ✅ `c.defending = false` 必须每场重置：不重置则上一场的防御姿态带进下一场，第一次挨打莫名减半
- ✅ 血条"拼串 vs 打印"错位：格子曾用 `System.out.print` 直打导致先出格子后出名字、括号空——已改 `sb.append` 统一拼串再返回
- ❌ **假会 ①（整数除法，今天最大的坑）**：以为 `50/100` 是 0.5
  - Java 里 **int / int = int**，小数直接扔掉——`50/100 = 0`，和 `(int)` 强转无关，除的那一刻就已经是 int
  - 后果：半血 `field = 0`，**血条掉一滴血就全空**
  - 修法：`HP * 1.0 / maxHP`——先让分子变身 double，后续全按小数算
  - 口诀：**int 相除必丢小数，想要小数先变身**
- ❌ **假会 ②（wins 无人自增）**：条件变量 `wins` 声明后从未 `++` → `wins != 0` 永远 false → 增强逻辑照现在的代码**永远不触发**。条件没人维护，条件就不成立
- ⚠️ **修歪又修正（增强块）**：注释写"最大生命值+10"，代码曾是 `c.HP+=10; c.HP=c.maxHP;`——加的 10 被第二行抹掉，增强失效
  - 正确：`c.maxHP += 10; c.HP = c.maxHP;`（上限和当前血一起涨，满血进下一场）

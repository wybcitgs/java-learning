## 假会清单（重点，下次复习只看这里）

### ❌ 假会 1：`this.name = name` 两个 name 的身份
- **我错答**：第一个是实参
- **正确**：`this.name` 里的 name 是**成员变量（字段）**；`=` 右边的 name 是**方法的形参**
- 记法：`this.` 修饰的 = 字段，没修饰的 = 形参
- 附带纠错：String 字段不赋值时默认值是 **`null`**，不是 0（0 是 int 的）

### ⚠️ 假会 2：参数在方法内改了，外面怎么拿到
- **我实操写对了但说不出原理**
- **标准表述**：方法内 `return size;` → 调用处 `size = addStudent(students, size);` 用返回值覆盖旧值
- 不是什么「在参数里加上」——是**返回值回传**
